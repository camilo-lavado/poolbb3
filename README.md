# poolbb3

## Descripción
Este proyecto es un asignador aleatorio de equipos para el juego Blood Bowl 3. Permite a los usuarios ingresar una lista de jugadores y asignarles equipos únicos de manera rápida y sencilla.

## Estructura del Proyecto
- `index.html`: Archivo principal que contiene la estructura HTML de la aplicación.
- `script.js`: Archivo JavaScript que maneja la lógica de asignación de equipos y la interacción del usuario.
- `style.css`: Archivo CSS que define el estilo visual de la aplicación.
- `README.md`: Este archivo, que proporciona información sobre el proyecto.

## Cómo Usar
1. Abre el archivo `index.html` en un navegador web.
2. Ingresa los nombres de los jugadores en el área de texto, uno por línea.
3. Haz clic en el botón "Asignar equipos" para recibir la asignación aleatoria de equipos.
4. Puedes limpiar la lista de jugadores haciendo clic en el botón "Limpiar".
